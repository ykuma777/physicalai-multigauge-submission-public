- Camera demo source and evidence were selected from `ykuma777/roboops-workshop`, `camera-observation` worktree, based on commit `006504eccf33801877dbe800c09e7243eb5867ca`. The displayed-run dashboard, wrapper, reports, and validation results were local changes not contained in that commit. The original worktree was left unchanged.
- `final_project/ros2_ws/src/inspection_task` is the original task package copied for its audited `pose_publisher`. Its package metadata declares Apache-2.0. The `camera_inspection` package also declares Apache-2.0. The repository includes the Apache-2.0 license text.
- CRANE+ V2 lecture packages, ROS 2, MoveIt, Ignition Gazebo, and the Docker base image are **not** vendored here. Their own licenses and authorship remain with their respective projects. Docker inspection on 2026-10-04 confirmed that the stopped original `physicalai-camera` container used image ID `sha256:b58ec74c019aacd9ce4818fa25fc5a9e0a1f22f8c9cd1f5260994bf15cd9eb63`, matching the published digest pinned in the new Compose file. Its three source/workspace paths were bind mounts from the original worktree. The new copy recreates the generated robot URDF from source.
- Historical run evidence was obtained in ROS domain 43. This copy uses ROS domain 44, VNC port 6083, and container `physicalai-camera-submission` for isolated reproduction. Only the runtime domain field changed in `configs/runtime.yaml`; the model bytes, image preprocessing settings, images, and weights were preserved. The model metadata records both the original and current runtime-config hashes.
